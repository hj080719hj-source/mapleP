# 메이플유 — 장비 완성 기대값 계산기

저장소: https://github.com/hj080719hj-source/mapleP

사이트: https://hj080719hj-source.github.io/mapleP/

한국 메이플스토리 PC 일반 월드의 장비 제작 기대 비용을 계산하는 정적 웹사이트입니다.
메인 주소 `/`에서 계산기가 바로 표시되며 처음 방문하면 마이스터링이 선택됩니다. 26개 장비·방어구 묶음을 직접 선택할 수 있습니다.
계산기의 기본 예시는 **몽환의 벨트 · INT 27% 이상 · 22성**입니다.

## 실행

Node.js 22 이상에서 `START.cmd`를 실행한 뒤 http://127.0.0.1:5173 에 접속하세요.
또는 프로젝트 폴더에서 `npm start`를 실행하세요. 실행용 패키지 설치는 필요 없습니다.

## 페이지와 기능

- `index.html`: 메인 계산기 (`/`), 상단 메뉴·버전 표시 없음
- `calculator.html`: 이전 주소 호환용, 쿼리를 유지해 `/`로 이동
- `potential.html`: 에픽→레전드리 등업 및 목표 옵션 비용, 미라클타임 선택
- `starforce.html`: 17~27성 기대 강화 횟수, 파괴 횟수, 스페어 수량과 비용
- `guide.html`: 계산 가정, 지원 범위, 원본 자료 링크
- 반응형 화면, 조건 브라우저 저장, 결과 복사, 인게임 강화·복구 비용 직접 입력

지원 레벨: 140·145·150·160·200·250. 16개 부위에 대해 넥슨 공개 잠재 표 92개를 저장했습니다.
250레벨 보조무기·벨트·귀고리·기계심장 표는 조회 결과가 없어 계산할 수 없습니다.
스크린샷의 24개 항목은 모두 표시되며 아케인·에테르넬은 부위를 선택해 장비 1개씩 계산합니다.
아스트라·데스티니의 특수 강화 규칙은 미검증이므로 스타포스 계산을 막고 잠재 계산만 제공합니다.

## 정확도와 범위

현재는 **계획용 베타 버전**입니다. 데이터 확인일은 2026-09-12입니다.

- 잠재 확률은 넥슨 공개 표의 로컬 스냅샷입니다. 세 줄 조합과 제한 옵션 재정규화를 계산합니다.
- 시작 등급(기본 에픽)부터 레전드리까지의 등업 비용과 천장을 포함합니다. 에디셔널도 별도 목표·시작 등급과 공통 미라클 설정으로 계산하며 큐브 아이템 비용은 제외합니다.
- 완전히 동일한 직전 옵션 재등장 제외 규칙은 생략했으므로 잠재 기대값은 근사값입니다.
- 스타포스는 2025년 변경된 확률과 2026-03-19의 스타캐치 상시 적용, 실패 유지, 두 가지 복구 방식을 반영합니다.
- **스타포스 기본 비용은 비공식 추정 산식입니다.** 인게임 값 검증 전입니다. 단계별 최종 비용을 입력해 대체할 수 있습니다.
- 성수 유지 복구 메소는 공개 계산기의 레벨·성수별 참고표를 자동 적용합니다. 인게임 값으로 덮어쓸 수 있습니다. 장비 수량은 공식 규칙을 적용합니다.
- 스타포스 평균은 선형 방정식으로 계산합니다. 무작위 시뮬레이션 오차는 없습니다. 입력 데이터의 정확도와는 별개입니다.
- 1+1 이벤트, 미확인 잠재, 슈페리얼·놀장·특수 장비는 자동 지원하지 않습니다.
- 장비 가격은 입력란 하나로 받습니다. 입력한 1개 가격을 최초 장비와 스페어에 공통 적용하며, 0이면 구매비를 제외합니다. 장비 직접 설정은 표시하지 않습니다.

## 0.2 화면 및 계산 옵션 개선

[BOOMBACK](https://www.boomback.com/ev)의 선택 흐름을 참고해 검정·주황색 화면으로 구성했습니다.
렙제별 장비 버튼, 시작/목표 슬라이더, 큰 요약 결과, 단계별 누적 비용 표를 제공합니다.
MVP·PC방 할인, 이벤트 프리셋, 5/10/15성 확정 성공, 개별 파괴 방지, 복구 메소 20% 할인을 추가했습니다.
복구 메소 입력은 할인 전 금액입니다. 강화 비용 직접 입력은 여전히 모든 할인이 반영된 최종 금액입니다.
범위는 최대 27성입니다. 파괴 방지와 복구 방식은 함께 자동 최적화할 수 있습니다. 참고 사이트와의 수치 일치는 검증하지 않았습니다.

## 현재 화면

메인에서 장비와 잠재 옵션, 목표 성수(17~27성)를 선택합니다. 시작 스타포스는 0~27성 중에서 선택하며 선택한 성수부터 계산합니다.
22성 이상에는 파괴 30% 감소를 적용하지 않습니다. 별 유지 복구는 최대 22성으로 돌아오며 22성 흔적은 스페어 4개가 필요합니다.
장비 아이콘은 넥슨 게임 이미지이며 BOOMBACK의 공개 스프라이트를 사용했습니다.

## 등업과 미라클타임

잠재를 선택하면 에픽부터 레전드리까지의 등업 비용과 이후 목표 옵션 재설정 비용을 합산합니다. 선택 없음이면 둘 다 제외합니다.
일반 등업 확률은 3.5%·1.4%, 미라클은 7%·2.8%입니다. 미라클은 등업 확률에만 적용합니다.
등급별 연속 실패 누적은 0회에서 시작하며 42회·107회 실패 후 다음 시도에서 확정 등업으로 계산합니다.
기대 등업 시도 횟수는 최대 N회인 기하분포의 평균 `(1-(1-p)^N)/p`입니다.
비용은 해당 레벨의 에픽·유니크 재설정 단가로 각각 계산합니다.
등업 성공 시 나오는 첫 레전드리 옵션도 목표 판정에 포함하므로 추가 옵션 재설정 기대 횟수는 `1/p-1`입니다.
옵션 등장 확률은 등업 성공 시에도 공개 레전드리 표와 같다고 가정합니다.
화면의 옵션 재설정 50%·90% 횟수는 등업 후 추가 재설정만의 값이며 등업 시도 횟수를 포함한 전체 분위수가 아닙니다.

- 등급·레벨별 단가: https://maplestory.nexon.com/news/update/737
- 미라클 공식 비교표: https://maplestory.nexon.com/News/Event/1086

## 파괴 방지 자동 선택

기본 활성화 상태에서 15·16·17성의 8개 방지 조합을 비교합니다. 선택한 복구 방식, 장비 가격, 이벤트, MVP·PC방 할인 조건에서 기대 비용이 가장 낮은 조합을 적용합니다. 동일 비용이면 방지 단계가 적은 쪽을 선택합니다.
성수를 직접 누르면 수동 모드로 전환됩니다. 확정 성공 단계는 방지하지 않습니다. 최종 강화비 직접 입력 단계는 현재 방지 설정을 고정하며 나머지 단계만 비교합니다.
별 유지 복구에서는 방지를 끄는 조합도 비교하므로 도달 가능한 모든 파괴 단계의 복구비가 필요합니다. 미입력 조합을 임의로 제외하거나 0원으로 취급하지 않습니다.
최적 선택의 정확도는 입력 가격과 강화비 추정 산식의 정확도에 따릅니다.

## 복구 공동 최적화

처음 방문하면 자동 복구가 선택됩니다. 각 파괴 단계에서 12성 복구와 성수 유지 확정 복구를 비교합니다. 파괴 방지 자동 선택도 켜져 있으면 방지 조합별 최적 복구 정책까지 계산해 가장 저렴한 조합을 적용합니다.
성수 유지 복구비는 `public/js/recovery-costs.js`의 표를 자동 적용합니다. 직접 입력한 값만 표보다 우선하며, 비우면 표의 값으로 돌아갑니다. 복구비는 할인 전 메소 단위이며 복구 20% 할인은 자동 적용합니다.
단계별 정책 평가와 개선을 반복해 재강화 및 반복 파괴까지 반영합니다. 23성 이상 파괴의 성수 유지 복구는 22성으로 돌아옵니다. 전체 과정을 한 가지 복구 방식으로 고정하는 것과 달리, 단계별로 서로 다른 복구 방식을 선택할 수 있습니다.
테스트에서는 모든 복구 정책을 열거한 결과와 비교하고, 파괴 방지와의 공동 최적화 및 잘못된 비용 입력 처리를 검증합니다.

## 자동 복구 비용표 출처

2026-09-12 기준 https://sf.sfcalc.workers.dev/script.js 의 `REC_TABLE`에서 지원 레벨 140·145·150·160·200·250의 15~22성 값 48개를 사용했습니다. 모든 값을 원본과 대조했습니다. 23~24성에서 파괴될 때는 22성 복구비를 적용합니다.
https://www.boomback.com/ev 의 공개 데이터와 비교하면 200레벨의 8개 값은 모두 일치하며, 다른 레벨에서는 19개 값에 차이가 있습니다. 145레벨의 정확한 표는 BOOMBACK 데이터에 없어 대조하지 못했습니다.
넥슨 공식 비용표 또는 직접 인게임 검증값이 아닙니다. 사이트에서도 참고표로 표시합니다. 차이 목록은 `public/data/recovery-sources.json`에 기록했습니다. 공식값이라고 주장하거나 누락된 레벨을 임의 보간하지 않습니다.

## 공용 장비 잠재 판정

공용 장신구와 기계심장은 주스탯 선택 시 STR·DEX·INT·LUK 중 하나라도 목표 이상이면 성공으로 계산합니다. 올스탯%는 각각의 주스탯에 더하지만 서로 다른 주스탯끼리 합산하지 않습니다. 여러 주스탯을 동시에 만족하는 결과는 한 번만 셉니다.
아케인·에테르넬 방어구 및 직업별 무기는 선택한 스탯만 계산합니다. 공격력%·마력%도 선택한 옵션만 인정합니다. 선택 없음은 잠재 비용을 제외합니다. 공용 장비라도 등업 비용은 동일하며, 옵션 재설정 기대 비용만 달라집니다.
